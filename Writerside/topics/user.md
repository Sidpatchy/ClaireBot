# /user

Reports various bits of info about a user, including:
- Discord ID
- Account Creation Date

## Command

### Syntax

```shell
/user [optional: user]
```

### Options

user (optional)
: The user you wish to get the details of.
<br/> If left blank, ClaireBot will report the details of whoever executed the command.
