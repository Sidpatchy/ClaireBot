# /server

Reports various bits of info about the (optionally specified) server / guild, including:
- Owner
- Creation Date
- Number of Roles
- Number of Members
- Number of Channels
  - Categories
  - Text Channels
  - Voice Channels

## Command

### Syntax

```shell
/server [optional: guildID]
```

### Options

guildID (optional)
: The ID of the guild you wish to gather info on. ClaireBot must be a member of the server.
